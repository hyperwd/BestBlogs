# 智能播客电台演示平台 - 演示说明

## 🎯 演示目标

向客户展示基于 AI 的多媒体播客平台的核心功能和技术实力，包括实时音频处理、智能转录翻译、实时新闻推送等功能。

## 🚀 快速启动演示

### 1. 环境准备
```bash
# 安装依赖
npm install

# 复制环境配置
cp .env.example .env.local

# 编辑配置文件，填入您的 Dify API 密钥
# NEXT_PUBLIC_DIFY_API_URL=https://your-dify-instance.com/v1
# DIFY_API_KEY=your-dify-api-key
```

### 2. 启动服务
```bash
# 启动开发服务器
npm run dev

# 服务启动在 http://localhost:3000
```

### 3. 访问演示界面
- **主界面**: http://localhost:3000
- **管理后台**: http://localhost:3000/admin

## 🔧 演示配置调整

### 添加自定义媒体源
1. 访问 `/admin/sources`
2. 点击"添加源"按钮
3. 填写源信息：
   ```
   名称：自定义演示源
   类型：电台/电视台/播客
   RSS URL：源的 RSS 地址
   语言：zh/en
   流媒体地址：实际播放地址
   ```

### 调整 AI 模型配置
编辑 `config/dify.js` 文件：
```javascript
module.exports = {
  workflows: {
    transcription: {
      workflowId: 'your-transcription-workflow-id',
      apiKey: 'your-transcription-api-key'
    },
    translation: {
      workflowId: 'your-translation-workflow-id',
      apiKey: 'your-translation-api-key'
    }
  }
}
```

### 修改演示数据
编辑 `config/sources.json` 添加更多演示源：
```json
{
  "id": "demo-source",
  "name": "演示媒体源",
  "type": "radio",
  "rssUrl": "https://example.com/rss",
  "streamUrl": "https://example.com/stream",
  "language": "en",
  "isActive": true
}
```

## 🔍 故障排除

### 常见问题
1. **Dify API 连接失败**
   - 检查 API 密钥配置
   - 确认 Dify 服务可用性
   - 查看网络连接状态

2. **音频播放失败**
   - 检查媒体源流媒体地址
   - 确认音频格式支持
   - 查看浏览器控制台错误

3. **转录功能不工作**
   - 检查文件大小限制（最大100MB）
   - 确认音频格式（MP3、WAV、M4A、OGG）
   - 查看 Dify 工作流状态
